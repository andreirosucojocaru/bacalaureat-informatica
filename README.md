# Bacalaureat – Informatică

Rezolvările mele, în C++, pentru subiectele de informatică de la examenul național de bacalaureat din **2014** și **2015**, pentru profilurile *matematică-informatică* și *științe ale naturii*.

## Conținut

| Folder | Sesiune | Profiluri |
| --- | --- | --- |
| [`2014/4iulie2014`](2014/4iulie2014) | Sesiunea din vară, 4 iulie 2014 | Matematică-informatică, Științe ale naturii |
| [`2014/29august2014`](2014/29august2014) | Sesiunea de toamnă, 29 august 2014 | Matematică-informatică, Științe ale naturii |
| [`2015/3iulie2015`](2015/3iulie2015) | Sesiunea din vară, 3 iulie 2015 | Matematică-informatică, Științe ale naturii |
| [`2015/28august2015`](2015/28august2015) | Sesiunea de toamnă, 28 august 2015 | Matematică-informatică, Științe ale naturii |

Fiecare rezolvare este un proiect Visual Studio (C++). Numele proiectelor indică profilul și problema: de exemplu, `Bacalaureat2014MI_III3` este rezolvarea pentru subiectul III, problema 3, la profilul matematică-informatică (`MI`), iar `SN` înseamnă științe ale naturii.

## Proveniență

Acest repository reunește două repository-uri mai vechi, `BAC2014` și `BAC2015`, cu tot istoricul lor de commit-uri.
